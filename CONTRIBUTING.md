# Contributing

This repository is published as a read-only reference. It does not accept
outside pull requests, and issues are turned off.

You are very welcome to fork it and take it wherever you like — the licence
permits it, and no attribution ceremony is required beyond keeping the notice.

Pull requests from outside the repository are closed automatically; that is not
a comment on the change, only on how this repository is run. Pull requests from
the owner and invited collaborators are left open, so the repository's own work
can still go through review.
