# Contributing

## Pull requests are not open yet

This project is in beta. The rule set, the Presentation IR and the override
syntax are all still moving, and a patch written against this week's internals
may not survive next week's. Reviewing outside changes under those conditions
would waste your time as much as mine, so incoming pull requests are closed
automatically.

That is a comment on the state of the project, not on your change.

Pull requests from the owner and invited collaborators are left open, so the
repository's own work can still go through review.

**This is temporary.** Once the internals settle — roughly, once the IR and the
rule contract stop changing between releases — contributions will be opened up
and this file will be replaced with a real contributor guide. If you want to
know when that happens, watch the repository for releases.

## What is welcome right now

**Bug reports.** Beta software needs them, and they are the most useful thing
you can send. Open an
[issue](https://github.com/wizdown/markdown-renderer/issues) with the markdown
that reproduces the problem, what you expected, and what you got instead.
A minimal snippet beats a whole document.

**Ideas and questions.** Also issues. A rule that fires when it should not, or
refuses when it should not, is worth hearing about even without a fix attached.

**Security reports.** Please do not open a public issue — see
[SECURITY.md](SECURITY.md).

**Forks.** Very welcome, and always will be. The MIT licence permits it and no
attribution ceremony is required beyond keeping the notice. If you are carrying
a change locally that you would have sent as a pull request, feel free to
mention it in an issue so it can be considered for upstream.
